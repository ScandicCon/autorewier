## 1. Обзор продукта

**AutoRewier** (бренд лендинга — **«ПОДКАПОТ»**) — B2C-сервис на Python для проверки б/у автомобиля перед покупкой или перепродажей (рынок РФ). Пользователь даёт ссылку на объявление, VIN и описание дефектов — продукт оценивает риски, считает стоимость ремонта и запчастей, проверяет историю по VIN и выдаёт понятный вердикт с PDF-отчётом.

Два канала доступа поверх единой бизнес-логики: **веб-кабинет** (Vue 3 SPA) и **Telegram-бот**. Монетизация — подписка **Pro** + разовые платные VIN-отчёты.

### Проблема

Покупка б/у авто — стресс и риск: скрытые дефекты, скрученный пробег, юридические ограничения, переплата. Обычный покупатель не умеет оценивать объявление и стоимость ремонта. Перекупщику нужна быстрая оценка экономики сделки.

### Видение

За пару минут любой человек получает по ссылке на объявление честный вердикт «брать / смотреть осторожно / не брать» с расчётом затрат, историей по VIN/гос-номеру и чеклистом осмотра.

## 2. Текущее состояние проекта (factual snapshot)

Проект **технически почти готов**. Объём: ~11 100 строк Python в `app/`, 26 тестовых файлов (≈166 тестов), 23 Vue-компонента/экрана, рабочий Telegram-бот, 6 Alembic-миграций. Ключевые тесты зелёные. В коде уже заведены Sentry, PostHog, OAuth-вход через соцсети, VIN-проверка, платежи ЮKassa, LLM-анализ (текст/фото/голос).

**Главный вывод:** оставшаяся работа — это в основном **не разработка, а вывод в прод** (боевые ключи, сквозной деплой, платежи и почта в бою, устойчивость парсинга) плюс несколько новых фич (пробивка гос-номера, усиление нейросетевого анализа) и публикация мобильных приложений.

**Главный финансовый риск:** полные VIN-отчёты Autocode (~60 ₽/шт). Держать платной опцией, не в безлимите Pro. Подробно — `docs/guides/HOSTING_COSTS.md`.

## 6. Новые фичи (детализация)

### 6.1. Усиление нейросетевого анализа машины
**Цель:** повысить точность и глубину анализа за счёт нейросетей.

Что уже есть: vision-анализ фото и текстовое обогащение через GPT-4o-mini, транскрипция голоса (Whisper).

Что добавить (требования):
- Структурированный vision-анализ фото авто: детекция повреждений (вмятины, ржавчина, перекрас, замятый ЛКП), оценка состояния по зонам кузова, флаг «крашеный/перекрашенный».
- Сводка «красных флагов» из всех источников (описание + фото + VIN + нормы пробега) единым ИИ-вердиктом с полями `evidence` (на чём основано), `confidence` (уверенность), `priority`.
- Оценка адекватности цены против рынка нейросетью (уже есть `market_comparison` — усилить).
- Контроль стоимости: vision-вызовы дороже текста — кэшировать результат по фото-хешу, лимиты на бесплатном тарифе.

### 6.2. Пробивка по гос-номеру (как «Номерограм»)
**Цель:** пользователь вводит госномер вместо VIN.

Как это работает технически: гос-номер сам по себе истории не содержит — сначала по ГРЗ определяется VIN (через провайдера: тот же Autocode умеет принимать ГРЗ, либо отдельный сервис конвертации ГРЗ→VIN), затем запускается обычный VIN-отчёт. То есть это **тонкая надстройка над уже готовой VIN-проверкой**, а не новая большая подсистема.

Требования:
- Поле ввода госномера (валидация формата РФ: `А123ВС777`) на веб и в боте.
- Сервис `grz_lookup`: ГРЗ → VIN через провайдера; кэш результата в Redis.
- Та же экономика и квоты, что у VIN (платная опция, не безлимит).
- Мягкая деградация: если по номеру VIN не найден — понятное сообщение и предложение ввести VIN вручную.

### 6.3. Мобильные приложения (App Store / Google Play)
**Цель:** нативные приложения после подтверждения юнит-экономики.

Рекомендуемый путь (минимум усилий, переиспользование Vue SPA): обернуть существующий фронтенд в **Capacitor** (WebView + нативные плагины) — один кодовая база, две сборки. Альтернатива — PWA + публикация через сервисы-обёртки. Требования и пошаговый план — в `docs/MASTER_PLAN.md`.

## 7. Нефункциональные требования

### 7.1. Производительность и масштаб
- Целевая нагрузка: **1000–2000 пользователей**, пик 30–60 одновременных, ~3000–5000 проверок/мес.
- Тяжёлые операции (парсинг, VIN, ИИ) — асинхронно через Redis-очередь, не блокируя ответ.
- Парсинг — через скрейпинг-API для устойчивости к капче и экономии памяти.
- Горизонтальное масштабирование воркеров; rate limiting и кэш в Redis; пул соединений к Postgres.
- Архитектура и конкретные шаги «чтобы не лёг от запросов» — `docs/guides/HOSTING_COSTS.md`.

### 7.2. Надёжность
- Мягкая деградация при отсутствии ключей/недоступности внешних сервисов.
- Бэкапы БД, идемпотентные миграции, план восстановления.

### 7.3. Безопасность
- Rate limiting на чувствительные эндпоинты; админ-API по токену; секреты только в окружении.
- Подтверждённые аккаунты; защита платёжного вебхука по IP-allowlist.

### 7.4. Соответствие и юридическое (РФ)
- Оферта, политика конфиденциальности, согласие на обработку ПДн (152-ФЗ) — ✅ страницы созданы, 🟡 проверить контент.
- Cookie consent для аналитики — ✅ реализован.
- Дисклеймеры: «цены ориентировочные, не оферта», «не является юридическим заключением».

### 7.5. Наблюдаемость и аналитика
- ✅ JSON-логи запросов с request-id; Prometheus `/metrics`.
- ✅ **Sentry** (код готов) — 🟡 нужен `SENTRY_DSN` в проде.
- ✅ **PostHog** (код готов) — 🟡 нужны ключи в проде. Воронки, удержание, A/B, feature flags.

## 9. Монетизация

| Тариф | Цена | Что входит | Себестоимость |
|---|---|---|---|
| **Free** | 0₽ | 3 базовые проверки/мес, VIN — демо | ~10₽/мес на юзера |
| **Pro** | 990₽/мес | Безлимит базовых проверок + 10 базовых VIN-отчётов/мес | ~30–80₽/мес |
| **Полный VIN / пакеты** | 490₽ (5) / 890₽ (10) / 1590₽ (20) | Глубокий Autocode сверх квоты | ~60₽/отчёт → маржа ~70% |

Ключевое правило экономики: **полный Autocode-отчёт не входит в безлимит** — иначе один активный перекупщик уводит Pro-подписку в минус. Подробный разбор — `docs/guides/HOSTING_COSTS.md`.

## 11. Риски

1. **Парсинг Avito** (капча/блок) — самая хрупкая точка воронки. → ScrapingBee + мониторинг + фолбэк.
2. **Стоимость Autocode** (~60₽/полный отчёт) — драйвер убытка. → платная опция, лимиты.
3. **Реклама вперёд экономики** — не масштабировать до подтверждения себестоимости на живых данных.
4. **Два UI** (Vue + Jinja) — риск двойной поддержки. → оставить Vue SPA основным.
5. **Внешние зависимости** (ScrapingBee, OpenRouter, ЮKassa, Resend, Autocode) — держать мягкую деградацию.
