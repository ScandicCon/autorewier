## 1. Что это за проект

**ПОДКАПОТ** — сервис помощи при покупке б/у авто: по ссылке на объявление оценивает риски, считает ремонт и запчасти, проверяет историю по VIN и гос-номеру, выдаёт вердикт и чеклист осмотра. Веб (Vue) + Telegram-бот. Аудитория — покупатели б/у авто, перекупы, автоподборщики.

**Текущий статус продукта:** технически готов и развёрнут, работает **бесплатно** (платежи пока не подключены — см. §4). MVP живой.

## 4. Заблокировано / требует решения 🔴

### Платежи
- **И ЮKassa, и Robokassa отказали** в подключении (категория услуги / самозанятый + новый сайт; причины не раскрывают).
- **Решение (выбрано):** запускаемся **бесплатно**, копим аудиторию и спрос. Платежи возвращаем **позже через ИП + банковский эквайринг** (Т-Банк/Сбер оценивают иначе, чем агрегаторы). ИП открывать **не сейчас**, а когда подтвердится спрос (у него фикс. взносы).
- Запасной вариант на самозанятом: попробовать Lava/Prodamus, но не приоритет.

### Реальный VIN / гос-номер
- Сейчас **демо-режим**. Для настоящих данных нужен **B2B-договор с Autocode** + баланс + ключи в Railway (`AUTOCODE_*`). Код полностью готов — включится автоматически.

## 5. Цели и план

### Этап «сейчас» — Бесплатный софт-запуск
**Цель:** первые **100 активных пользователей** (сделали ≥1 проверку и вернулись).
- Сервис бесплатный, позиционирование — аналитика помощи при покупке.
- Контент: TikTok (мультики-хорроры + рубрика «к 100») + Telegram-аутрич.
- Метрика: PostHog → «inspection_created unique users».

### Этап «дальше» — Монетизация и реальные данные
- Подтвердить спрос на живых данных (себестоимость, конверсия).
- Открыть **ИП** → банковский эквайринг → включить оплату Pro + пакеты (код готов).
- Подключить **Autocode** → реальный VIN и пробивка по гос-номеру.

### Этап «масштаб и рост»
- Redis в Railway (кэш/очередь) — держать нагрузку 1–2k (см. HOSTING_COSTS).
- **Реклама** — только после подтверждения юнит-экономики (CAC < LTV).
- **Мобильные приложения** (App Store / Google Play) — через обёртку Vue SPA (Capacitor).
