## 1. Что это за проект

**ПОДКАПОТ** (тех. имя AutoRewier) — сервис помощи при покупке б/у автомобиля. По ссылке на объявление: оценивает риски, считает стоимость ремонта и запчастей, проверяет историю по **VIN** и **гос-номеру**, анализирует **фото** нейросетью, выдаёт вердикт и чеклист осмотра. Два интерфейса: веб (Vue 3) и Telegram-бот. Аудитория — частные покупатели, перекупы, автоподборщики.

**Технологии:** FastAPI + PostgreSQL/Supabase, Vue 3 + Vite, aiogram, Playwright/ScrapingBee для парсинга, OpenRouter (GPT-4o-mini, vision, Whisper), Redis (кэш/очередь), Docker. Деплой: Railway (бэк) + Vercel (фронт).

**Текущий статус:** технически готов, развёрнут, **работает бесплатно** (платежи пока не подключены — см. §5). MVP живой.

## 5. Заблокировано / требует решения 🔴

### Платежи
- **И ЮKassa, и Robokassa отказали** в подключении (категория услуги + самозанятый + новый сайт; причины не раскрывают).
- **Решение (выбрано):** запускаемся **бесплатно**, копим аудиторию и подтверждаем спрос. Платежи — **позже через ИП + банковский эквайринг** (Т-Банк/Сбер оценивают иначе, чем агрегаторы). ИП открывать **не сейчас**, а когда есть спрос (у ИП фикс. взносы ~50k ₽/год).
- Запасной вариант на самозанятом: Lava/Prodamus — но не приоритет.

### Реальные данные по VIN / гос-номеру
- Сейчас **демо-режим**. Для реальных данных нужен **B2B-договор с Autocode** + пополненный баланс + ключи `AUTOCODE_*` в Railway. Код готов — включится автоматически, в т.ч. квоты и кэш.
