# Подключение Autocode (проверка авто по VIN)

> Как сделать так, чтобы пользователи получали реальную историю авто по VIN. Код интеграции уже готов — нужен B2B-доступ к Автокоду, пополненный баланс и ключи в Railway. После этого квота VIN включится автоматически.

---

## Как это устроено в продукте

- Сервис уже умеет запрашивать отчёт по VIN через API Автокода (`request_vin_report`). Сейчас работает **демо-режим** (без ключей — отдаёт заглушку).
- Как только впишешь реальные ключи → `autocode_enabled = true` → **включается квота**: на Pro 10 отчётов/мес включено, сверх — пакеты (защита от минуса, уже реализована).
- Отчёты у Автокода — **предоплатные**: списываются с баланса твоего B2B-аккаунта. То есть «куда положить деньги» = **пополнить баланс в кабинете Автокода для бизнеса**.

---

## Шаг 1. Получить B2B-доступ к Автокоду

1. Зайди на **avtocod.ru/for-business** → оставь заявку на подключение для бизнеса.
2. Выбери способ **«Доступ по API»** (нам нужен именно он, не только личный кабинет).
3. Уточни у менеджера тарифы и **стоимость отчётов** (базовый/полный) — точную цену они называют под договор. Контакты: **b2b@avtocod.ru**, тел. **+7 (499) 110-49-83**.
4. Самозанятый/ИП — уточни, с кем они заключают договор (возможно, потребуется ИП; спроси прямо).

## Шаг 2. Пополнить баланс

После активации B2B-аккаунта **пополни баланс** в кабинете Автокода — с него будут списываться отчёты. Начни с небольшой суммы для теста (например, на 10–20 отчётов).

## Шаг 3. Получить ключи и UID отчёта

В кабинете API Автокода возьми:
- **логин/идентификатор** для API,
- **пароль/секрет**,
- **домен/endpoint** API,
- **UID типа отчёта** — выбери, какой отчёт продаёшь (базовый дешевле, полный дороже и содержательнее), у него будет свой идентификатор.

## Шаг 4. Вписать в Railway (сервис autorewier → Variables)

| Переменная | Значение |
|---|---|
| `AUTOCODE_USER` | логин/идентификатор API |
| `AUTOCODE_PASSWORD` | пароль/секрет |
| `AUTOCODE_DOMAIN` | домен/endpoint API Автокода |
| `AUTOCODE_REPORT_TYPE_UID` | UID выбранного типа отчёта |

Сохрани → дождись передеплоя. Как только все четыре заданы — `autocode_enabled` станет `true`, VIN перестанет быть демо, и **включится квота**.

## Шаг 5. Настроить экономику квоты под реальную цену

Когда узнаешь реальную себестоимость отчёта, проверь число включённых отчётов в Pro:
- Правило: `включено_в_Pro × себестоимость < 955 ₽` (чистая подписка после комиссии).
- Сейчас стоит `PRO_VIN_REPORTS_INCLUDED = 10` (рассчитано на ~60 ₽/отчёт → запас ~355 ₽).
- Если отчёт дороже — уменьши `PRO_VIN_REPORTS_INCLUDED` в Railway. Цены пакетов — в `app/services/subscription.py` (`REPORT_PACKS`).

## Шаг 6. Проверить

1. Создай проверку с реальным VIN → должен прийти настоящий отчёт (история, владельцы, ограничения), а не демо.
2. Сделай больше отчётов, чем квота → должно предложить докупить пакет (статус 402 / сообщение в UI).

---

## Важно про деньги

- **Себестоимость Autocode перекладывается на пользователя** через подписку/пакеты — в инфраструктуру она не входит (это переменная статья). Поэтому держи цену отчёта/квоту так, чтобы каждый отчёт был в плюс.
- Глубина отчёта (базовый vs полный) — главный рычаг себестоимости. Для старта можно взять базовый (дешевле), полный — как опцию/пакет.
