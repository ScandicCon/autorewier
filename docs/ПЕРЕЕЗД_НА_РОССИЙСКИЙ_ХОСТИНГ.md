# Переезд на российский хостинг (Yandex Cloud)

## Зачем

Сейчас фронт на Vercel, бэкенд на Railway, шрифты с Google Fonts — вся
инфраструктура зарубежная. В России она работает нестабильно, из-за чего:

1. **Продукт не работает без VPN** — фронт не может достучаться до бэкенда.
2. **Сайт не индексируется Яндексом** — робот Яндекса ходит из РФ и не может
   стабильно обойти страницы.
3. **Отказ платёжной системы** — модератор (из РФ) открывает сайт и видит
   нерабочий сервис.

Решение: всё на одной машине в российском облаке, под одним доменом
`www.podcapot.ru`. Проект к этому готов: `Dockerfile` собирает фронт и бэкенд в
один образ, Caddy сам получает HTTPS-сертификат.

---

## Что заказать в Yandex Cloud

1. **Compute Cloud → виртуальная машина**
   - ОС: Ubuntu 22.04
   - vCPU: 2 (уровень 100%), RAM: 4 ГБ, диск: 30–40 ГБ SSD
     (4 ГБ нужны из-за Playwright/Chromium для парсинга Avito)
   - Публичный IP: **статический** (важно, на него пойдёт DNS)
   - SSH-ключ: добавить свой
2. **Managed Service for PostgreSQL** (опционально, но рекомендуется)
   - PostgreSQL 16, минимальная конфигурация
   - Даёт авто-бэкапы и обслуживание. Если экономим — можно пропустить, в
     `deploy/docker-compose.prod.yml` уже есть контейнер `postgres`.

Ориентир по деньгам: VM ~1500–3000 ₽/мес; managed PostgreSQL добавит
~1500–3000 ₽/мес. Без managed-БД выходит заметно дешевле.

## Шаг 1. DNS

В панели управления доменом `podcapot.ru` (там же, где подтверждали Google):

| Тип | Имя | Значение |
|---|---|---|
| A | `@` | IP вашей VM |
| A | `www` | IP вашей VM |

Старые записи, ведущие на Vercel (CNAME на `cname.vercel-dns.com` и т.п.),
нужно удалить. Обновление DNS занимает от 15 минут до нескольких часов.

## Шаг 2. Подготовка сервера

Подключиться по SSH и установить Docker:

```bash
ssh ubuntu@ВАШ_IP

sudo apt update && sudo apt upgrade -y
curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker $USER
exit   # выйти и зайти снова, чтобы применилась группа
```

## Шаг 3. Код и настройки

```bash
ssh ubuntu@ВАШ_IP
git clone https://github.com/ScandicCon/autorewier.git
cd autorewier
cp .env.example .env
nano .env
```

Что обязательно указать в `.env`:

```
APP_DOMAIN=podcapot.ru
ENVIRONMENT=production
WEB_SECRET_KEY=<длинная случайная строка>
POSTGRES_PASSWORD=<придумать пароль>

# Если используете Managed PostgreSQL — укажите его строку подключения,
# иначе оставьте пустым и будет использован контейнер postgres:
# DATABASE_URL=postgresql+asyncpg://user:pass@host:6432/db

OPENROUTER_API_KEY=<ключ>
SCRAPINGBEE_API_KEY=<ключ, если есть>
ADMIN_API_TOKEN=<длинная случайная строка>

# Оплата (после одобрения кассы)
PRODAMUS_FORM_URL=https://podcapot.payform.ru
PRODAMUS_SECRET_KEY=<из личного кабинета>
```

Сгенерировать секреты: `openssl rand -hex 32`

## Шаг 4. Запуск

```bash
cd ~/autorewier
docker compose -f deploy/docker-compose.prod.yml up -d --build
```

Первая сборка идёт 5–15 минут (ставится Chromium). Затем:

```bash
# статус контейнеров
docker compose -f deploy/docker-compose.prod.yml ps
# логи бэкенда
docker compose -f deploy/docker-compose.prod.yml logs -f api
```

Caddy автоматически получит HTTPS-сертификат, как только DNS будет указывать на
сервер. Отдельно ничего настраивать не нужно.

## Шаг 5. Проверка

1. Открыть `https://www.podcapot.ru` **без VPN** — сайт должен работать.
2. Проверить API: `https://www.podcapot.ru/api/v1/health`
3. Сделать тестовую проверку авто по ссылке на объявление.
4. `http://podcapot.ru` должен редиректить на `https://www.podcapot.ru`.

## Шаг 6. После переезда

- **Vercel и Railway**: не удалять сразу, оставить на неделю как запасной
  вариант. Убедившись, что всё стабильно, — отключить, чтобы не платить.
- **Яндекс.Вебмастер**: «Переобход страниц» → отправить главную. Теперь робот
  сможет её скачать, и индексация пойдёт.
- **Prodamus**: подать заявку повторно — сайт теперь открывается из РФ.
- **Шрифты**: положить файлы в `frontend/public/fonts/` (см. README там же).
- **Бэкапы**: если БД в контейнере, настроить регулярный дамп:
  ```bash
  docker exec podcapot-postgres pg_dump -U podcapot podcapot > backup_$(date +%F).sql
  ```
