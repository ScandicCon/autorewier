# Индексация сайта: Яндекс.Вебмастер + Google Search Console

Цель Фазы 0: сайт `podcapot.ru` попадает в индекс и начинает получать бесплатный
поисковый трафик. Код уже готов (`robots.txt`, `sitemap.xml`, мета-теги, canonical,
Open Graph). Осталось подтвердить владение сайтом в двух панелях и отдать им sitemap —
это делается руками, ключей/кода не требует.

Домен везде указан как **https://www.podcapot.ru** (robots, sitemap, canonical
совпадают). Подтверждайте именно этот вариант с `www`.

---

## 1. Подготовка (уже в коде)

- `frontend/public/robots.txt` — открыт для индексации, закрыты приватные разделы,
  указан Sitemap.
- `frontend/public/sitemap.xml` — 4 публичные страницы (главная, контакты, оферта,
  политика).
- `frontend/index.html` — заготовлены две закомментированные строки для кодов
  подтверждения (метод «HTML-тег»):
  ```html
  <!-- <meta name="yandex-verification" content="ВАШ_КОД_ЯНДЕКСА" /> -->
  <!-- <meta name="google-site-verification" content="ВАШ_КОД_GOOGLE" /> -->
  ```

## 2. Яндекс.Вебмастер

1. Открыть https://webmaster.yandex.ru → «Добавить сайт» → ввести
   `https://www.podcapot.ru`.
2. Выбрать способ подтверждения **«Мета-тег»**. Яндекс покажет строку вида
   `<meta name="yandex-verification" content="abc123..." />`.
3. Скопировать значение `content`, вставить его в `frontend/index.html` в
   раскомментированную строку `yandex-verification`, задеплоить фронт (Vercel).
4. Вернуться в Вебмастер → «Проверить». После успеха:
   - «Индексирование» → «Файлы Sitemap» → добавить
     `https://www.podcapot.ru/sitemap.xml`.
   - «Переобход страниц» → отправить главную и ключевые URL вручную (ускоряет).
5. Проверить «Диагностика» — не должно быть критичных ошибок.

## 3. Google Search Console

1. Открыть https://search.google.com/search-console → «Добавить ресурс» →
   тип **«Ресурс с префиксом URL»** → `https://www.podcapot.ru`.
   (Вариант «Домен» требует подтверждения через DNS — тоже годится, если удобнее.)
2. Способ подтверждения **«Тег HTML»** → скопировать `content` из
   `<meta name="google-site-verification" ... />`.
3. Вставить в `frontend/index.html` в строку `google-site-verification`,
   задеплоить, нажать «Подтвердить».
4. После подтверждения: «Файлы Sitemap» → добавить
   `https://www.podcapot.ru/sitemap.xml`.
5. «Проверка URL» → ввести главную → «Запросить индексирование».

## 4. Что смотреть дальше (еженедельно)

- **Вебмастер / GSC:** число страниц в индексе (должно вырасти с 0), поисковые
  запросы, показы, клики.
- Появление сайта в выдаче по бренду «подкапот» — первый сигнал, что индексация
  пошла.
- Ошибки сканирования (robots, 404, редиректы) — чинить сразу.

## 5. Частые ошибки

- Подтвердили `podcapot.ru` без `www`, а canonical/sitemap на `www` — заводите
  ресурс именно на тот хост, что в canonical (`www`). Либо настройте 301-редирект
  apex → www и подтвердите оба.
- Забыли задеплоить фронт после вставки мета-тега — подтверждение не пройдёт,
  тег должен быть в реально отданном `index.html`.
- Sitemap отдаётся, но пустой/старый — проверьте, что по
  `https://www.podcapot.ru/sitemap.xml` открывается актуальный XML.
